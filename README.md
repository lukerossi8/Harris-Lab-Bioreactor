# Harris-Lab-Bioreactor
This repository contains MATLAB scripts that model cell dynamics in a rocking bioreactor environment. It models cell motion in a periodic background flow field based on prior CFD simulation data. It also models cellular bonding. Users can customize the length of the simulation, the number of cells, and the cells' initial positions.
